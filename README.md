## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech

- Next.js (App Router) + TypeScript + Tailwind CSS
- Vehicle data in `data/vehicles.json`
- Centralized config in `src/lib/config.ts`

## Features

- Home, Inventory (search/filter/sort), Vehicle detail with gallery
- WhatsApp & Call CTAs with official numbers
- Availability states (Available / Reserved / Sold)
- Related vehicles, SEO metadata, responsive design
